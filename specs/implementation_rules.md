# Implementation Rules

## General

Do not redesign.

Do not replace components.

Only refine visuals.

---

## Performance

Avoid unnecessary re-renders.

Prefer CSS transitions.

Keep animations lightweight.

---

Keyboard navigation.

Buttons minimum 44px.
