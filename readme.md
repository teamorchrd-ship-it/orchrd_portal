# Orchrd Design Specification v1.0

## Objective

This repository contains the official UI implementation specifications for Orchrd.

These specifications are the single source of truth for every frontend implementation.

The current project already exists.

This is NOT a redesign.

This is NOT a rewrite.

This is an implementation refinement.

---

## Important Rules

You are NOT the designer.

You are the implementation engineer.

Do NOT invent:

- layouts
- spacing
- colors
- typography
- interactions
- responsiveness
- animations

Only implement what is documented.

If any specification is missing,
STOP
and ask.
